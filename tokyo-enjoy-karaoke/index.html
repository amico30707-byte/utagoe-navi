「60歳をすぎてから、人前で歌える場所があったらいいな」 「カラオケが好きだけれど、大きなホールで歌ったことはない」

そんな方に知ってほしいのが、東京都がひらいている「TOKYO縁（エン）ジョイ！」です。正式な名前は「第6回『TOKYO縁（エン）ジョイ！』2027 東京都シニア・コミュニティ交流大会」で、その中にカラオケの部門があります。

わたしは、息子といっしょにたくさんの歌のコンクールに出てきました。会場で歌うと、ふだんのカラオケとはちがう、はりつめた気持ちと、歌いおえたあとのうれしさがあります。この大会は、そんな体験を、シニアの方が気軽に味わえる場だと思います。

この記事では、公式の発表でたしかめられたことをもとに、カラオケ大会のことをまとめます。

どんな大会？

「TOKYO縁ジョイ！」は、東京都に住むシニアの方が、しゅみを通じて人とつながることを目的にした交流大会です。カラオケのほかにも、囲碁・将棋・健康マージャン、eスポーツ、ダンススポーツなどの種目があります。

公式の発表によると、カラオケの定員は今年度から広がって120名になりました。大会ぜんたいでは、およそ1,420名が参加できる大きさです。

うまさをきそうだけでなく、同じしゅみを持つ人と出会えることも、この大会の大きな楽しみといえます。

だれが出られる？

項目 内容
住んでいるところ 東京都内
年れい 60歳以上（2027年4月1日の時点）
定員 120名（多いときは抽選）

年れいは「2027年4月1日の時点で60歳以上」です。いま59歳の方でも、この日までに60歳になる方は出られます。生まれた日をもう一度たしかめておきましょう。

カラオケの中で、年れいや男女などで部門が分かれているかどうかは、公式サイトでご確認ください。

当日の集合時間や、歌う順番、おわる時間などは、公式サイトでご確認ください。申しこんだあとに、くわしい案内がとどくことが多いので、よく読んでおくと安心です。

曲のきまり

公式の発表では、曲のえらび方や、歌う時間、キー（高さ）の変え方などのきまりは、のっていませんでした。曲のきまりは、公式サイトでご確認ください。

申しこみのときに曲名を書くこともあるので、早めに歌いたい曲をしぼっておくと、あわてずにすみます。

申しこみの流れ

申しこみの方法は2つです。

  • Webで申しこむ
  • 参加申込書を郵送する

申込書は、大会のホームページからダウンロードするか、募集案内についているものを使います。

郵送の場合は「12月3日必着」です。12月3日に出すのではなく、この日までにとどいている必要があります。年末が近い時期なので、余裕をもって出しましょう。

  1. 公式の案内を読んで、対象と日程をたしかめる
  2. Webか郵送で申しこむ
  3. 応募が多いときは抽選
  4. 大会の案内を受けとる
  5. 当日、会場で歌う

審査と結果

審査のしかたや、賞の種類、結果の知らせ方は、公式の発表にはのっていませんでした。公式サイトでご確認ください。

なお、公式の発表によると、大会に参加した方のうち、「東京アプリ」に登録して、会場でアンケートに答えるなど決められた手順をふんだ方は、東京ポイントが200ポイントもらえるそうです。くわしい手順は、公式サイトでご確認ください。

こんな方に向いている

  • 東京都に住んでいて、60歳以上の方
  • カラオケが好きで、大きなホールで歌ってみたい方
  • 同じしゅみの仲間を見つけたい方
  • 1,000円という、参加しやすい費用で出てみたい方
  • 本格的なコンクールの前に、人前で歌う練習をしたい方

大人の方が出られるほかの歌の大会については、こちらの記事でもまとめています。大人が出られる歌のコンクール。会場で歌う大会と動画で応募する大会、自分に合うえらび方

出る前の準備

曲を早めに決める

いちばんの準備は、曲えらびです。高い声が苦しくなくて、自分がいちばん気持ちよく歌える曲をえらびましょう。ホールでは声がひびくので、いつもより少しゆったり歌うくらいがちょうどよいこともあります。

立って歌う練習をする

カラオケボックスでは、すわって歌うことが多いと思います。でも、会場では立って歌うことがほとんどです。家でも、立って、前を向いて歌う練習をしておくと、本番でおちつけます。

歌う姿を録画してみる

スマホで歌う姿をとって見かえすと、姿勢や表情に気づけます。歌の動画審査、スマホでのきれいなとり方。おうちでできる10のコツ

緊張とうまくつきあう

大きなホールでは、だれでも緊張します。ゆっくり息をはいてから歌いはじめると、声が出やすくなります。緊張とのつきあい方は、こちらの記事もどうぞ。本番で緊張する子へのことば。歌のコンクール前に親ができること

当日の持ち物と体調

水やのどあめ、上着、案内の書類などを前の日にまとめておきましょう。1月の大会なので、寒さ対策もわすれずに。のどの調子がわるいときは、むりをしないことも大切です。

会場で歌う大会の一般的な流れ

ここからは、この大会にかぎらない、会場で歌う大会によくある流れのお話です。この大会の当日の流れは、とどいた案内でたしかめてください。

  1. 受付で名前を伝え、番号や案内を受けとる
  2. 客席やひかえの場所で、自分の番を待つ
  3. 名前や曲名がよばれたら、ステージに上がる
  4. 前奏が流れはじめたら、マイクをかまえて歌う
  5. 歌いおえたら、おじぎをしてステージをおりる

自分の番まで時間があくこともあるので、のどをかわかさないように、こまめに水をのみましょう。ほかの方の歌を聞くのも、大会ならではの楽しみです。すてきだなと思った歌い方は、次の練習のヒントになります。
