練習・発声のコツ

デュエット・二人で歌うときのコツ。親子・夫婦・友だちと楽しく声を合わせるには

更新日：2026年11月7日 ・ 書いた人：うみ

「親子でいっしょに歌ってみたい」 「カラオケで、夫婦や友だちとデュエットをしてみたいけれど、うまく合わない」

ひとりで歌うのとはちがって、二人で歌うときには、ちょっとしたコツがあります。声の高さも、声の大きさも、歌うくせも、人によってちがいます。だからこそ、二人の声がぴたりと合ったときは、ひとりで歌うときとはまたちがう、うれしさがあります。

わたしは息子といっしょに、たくさんのコンクールに出てきました。歌は、ひとりでもなかまとでも楽しめるものだと感じています。

この記事では、デュエット（二人で歌うこと）を楽しむためのコツを、曲のえらび方から、練習のしかた、本番の心がまえまで、順番にまとめます。親子、夫婦、友だちなど、どんな組み合わせでもつかえる内容です。

デュエットにはいろいろな形がある

ひとくちにデュエットといっても、歌い方にはいくつかの形があります。まずは、どんな形で歌うかを二人で決めておくと、練習がすすめやすくなります。

同じメロディを二人で歌う（ユニゾン）

二人とも同じメロディを、同じタイミングで歌う形です。いちばんかんたんで、はじめてのデュエットにぴったりです。小さなお子様といっしょに歌うときも、この形からはじめるとよいと思います。

かわりばんこに歌う

1番はAさん、2番はBさん、さいごのサビは二人で、というように、パートを分けて歌う形です。カラオケのデュエット曲には、この形のものが多いです。自分の番がわかりやすいので、歌になれていない方でも参加しやすいです。

ハモる（ちがうメロディを重ねる）

一人がメロディを歌い、もう一人がちがう高さのメロディを重ねる形です。うまく重なると、とてもきれいなひびきになります。ただ、少しむずかしいので、なれてきてからの楽しみにとっておいてもよいと思います。ハモリのくわしい練習は、こちらの記事にまとめています。ハモリの練習。ハモれるようになるコツと、家でできる練習

曲のえらび方

二人とも知っている曲をえらぶ

デュエットでいちばん大切なのは、二人ともその曲をよく知っていることです。どちらか一人だけが知っている曲だと、もう一人が「ついていく」だけになり、楽しさが半分になってしまいます。

  • 二人とも好きな曲
  • メロディをなんとなく口ずさめる曲
  • テンポがはやすぎない曲

こうした曲からえらぶと、練習がスムーズです。

組み合わせごとのえらび方のヒント

  • 親子：お子様が知っている童謡や、学校で習った歌、アニメの歌など。お子様が「歌いたい」と言った曲を大切にしましょう。
  • 夫婦：二人が若いころによく聞いた曲や、思い出の曲。カラオケのデュエット曲も、えらびやすいです。
  • 友だち：いっしょに出かけたときに聞いた曲や、二人がよく話題にする歌手の曲など。

どの組み合わせでも、「この歌、いっしょに歌いたいね」と二人で決めることが、いちばんのスタートです。

長さは短めから

はじめは、2分から3分くらいの短めの曲や、1番だけを歌うのがおすすめです。長い曲を通して歌うと、どこかでずれたときに立てなおすのがたいへんです。短い曲で「合った」という気持ちを味わってから、少しずつ長い曲にすすんでいきましょう。

声の高さ（キー）をどう決める？

二人の歌いやすい高さはちがう

男の人と女の人、大人とお子様では、らくに出せる声の高さがちがいます。同じ曲を同じ高さで歌うと、どちらかが高すぎたり、低すぎたりして、苦しくなることがあります。

決め方の手順

  1. まず、もとの高さで、二人がそれぞれ1回ずつ歌ってみる
  2. 「高くて苦しい」「低くて声が出にくい」ところがないか、話し合う
  3. カラオケや伴奏の音源で、高さを少し上げ下げしてみる
  4. 二人とも「らくに歌える」と感じる高さを、さがす

ぴったりの高さが見つからないときは、男の人がメロディを1つ下の高さ（オクターブ下）で歌うなど、同じメロディでも高さをずらして歌う方法もあります。むずかしく考えず、「二人ともむりをしない」ことを大切にしてください。

お子様と歌うときは、お子様に合わせる

親子で歌うときは、大人がお子様の高さに合わせてあげましょう。小さなお子様ののどはデリケートです。大人に合わせて、むりに低い声や高い声を出しつづけると、のどがつかれてしまいます。

声の大きさのバランス

どちらかが大きすぎると、もう一人が聞こえなくなる

デュエットで、意外とむずかしいのが声の大きさです。声が大きい人がいつもの調子で歌うと、もう一人の声がかくれてしまいます。

  • 声が大きい人は、少しおさえめに歌ってみる
  • 声が小さい人は、口をしっかり開けて、ことばをはっきり言う
  • 録音して、二人の声がどちらも聞こえるか、たしかめる

相手の声を聞きながら歌う

ひとりで歌うときは、自分の声を聞いていれば大丈夫です。でも、二人で歌うときは、相手の声を聞きながら歌うことが大切です。「自分の声が半分、相手の声が半分聞こえる」くらいを目指すと、声がまとまりやすくなります。

息とタイミングを合わせる練習

歌い出しの合図を決める

二人の歌がずれやすいのは、歌い出しです。だれが合図を出すかを決めておきましょう。

  • 目を合わせて、うなずく
  • 二人で同時に、小さく息をすう
  • 一人が「せーの」と小さく言う（練習のとき）

とくに、同時に息をすうことは、とても効果的です。息をすうタイミングがそろうと、歌い出しもそろいやすくなります。

息つぎの場所をそろえる

二人で同じメロディを歌うときは、息つぎ（ブレス）の場所もそろえておきましょう。歌詞カードに、二人で「ここで息をすう」というしるしをつけておくと、わかりやすくなります。

ことばの終わりをそろえる

ことばの終わりの音を、どこまでのばすか、どこで切るかも、二人で決めておくと、ぐっとまとまります。片方が長くのばして、もう片方が早く切ると、少しばらばらに聞こえてしまいます。

おすすめの練習の流れ

  1. 歌詞を、二人で声に出して読む（リズムをたしかめる）
  2. メロディを「ラ」や「ル」だけで、二人で歌う
  3. 歌詞をつけて、ゆっくりのテンポで歌う
  4. もとのテンポにもどして、通して歌う
  5. 録音して、二人で聞いてみる

1回の練習は、15分から20分くらいでじゅうぶんです。のどがつかれたら、水をのんで休みましょう。

組み合わせごとの楽しみ方

親子で歌うとき

お子様と歌うときは、上手に合わせることより、いっしょに歌う時間を楽しむことを大切にしてください。ずれても、まちがえても、「楽しかったね」と笑い合えれば、それがいちばんです。

  • お子様のペースに合わせて、テンポをゆっくりにする
  • お子様が歌いやすいところを、多めにまかせる
  • 「いまの、ぴったり合ったね」と、合ったところをほめる

おじい様・おばあ様とお孫さんで歌う楽しみ方は、こちらの記事でも紹介しています。孫といっしょに歌う。シニアと子どもの歌の時間

夫婦で歌うとき

夫婦でのデュエットは、思い出の曲を歌うのもすてきです。どちらかが歌になれていないときは、なれている人が相手のペースに合わせると、楽しく歌えます。「ここはもっとこうして」と言いすぎず、二人で決めていくのがおすすめです。

友だちと歌うとき

友だちとのデュエットは、気軽に楽しめるのが魅力です。おたがいの好きな歌を教え合うと、新しい曲に出会うきっかけにもなります。歌い方のくせがちがっても、「それもいいね」と受けとめ合えると、楽しい時間になります。

うまく合わないときは

ずれても止まらない

本番で少しずれてしまっても、歌を止めずに続けましょう。相手の声をよく聞いて、次のフレーズの頭で合わせなおせば大丈夫です。

「どちらが悪い」と言わない

合わないときに、「そっちがずれた」と言い合うと、楽しい気持ちがしぼんでしまいます。録音を聞いて、「ここ、二人とも少しずれたね。次は合図を決めようか」と、二人の問題として話し合いましょう。

のどを大切に

楽しくて、つい何回も歌ってしまうこともあると思います。のどに痛みやかすれを感じたら、その日はお休みしましょう。痛みやかすれが続くときは、耳鼻科などのお医者さんに相談してください。

まとめ

  • デュエットには「同じメロディ」「かわりばんこ」「ハモる」などの形がある
  • 曲は、二人ともよく知っていて、短めのものからえらぶ
  • 声の高さは、二人ともむりなく歌えるところをさがす
  • 声の大きさは、相手の声も聞こえるバランスを目指す
  • 歌い出しの合図や、息つぎの場所を二人でそろえる
  • ずれても止まらず、二人で楽しむ気持ちを大切にする
