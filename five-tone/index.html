練習・発声のコツ

5トーンスケールの発声練習とは？やり方とコツを、はじめての方にやさしく

更新日：2026年11月11日 ・ 書いた人：うみ

「ボイトレで、5トーンスケールという練習が出てきたけれど、どういうもの？」 「ドレミファソを歌うだけで、本当に練習になるの？」

歌の教室や動画で、「5トーンスケール」ということばを目にしたことがある方も多いと思います。名前だけ聞くと、むずかしそうに感じるかもしれません。でも、やり方はとてもシンプルで、お子様から大人の方まで、だれでもとり入れやすい発声練習です。

わたしは、息子といっしょに、たくさんの歌のコンクールに出てきました。歌の練習では、こうしたシンプルな発声練習を、毎日少しずつ続けることが大切だと感じています。

この記事では、発声練習の5トーンスケールとは何か、そのやり方とコツ、よくある失敗と直し方まで、やさしくまとめてお話しします。

5トーンスケールとは

5つの音をのぼって、おりる練習

5トーンスケールとは、「5つの音」の「音階」という意味です。ドから数えて5つの音、つまり「ド・レ・ミ・ファ・ソ」をのぼって、また「ソ・ファ・ミ・レ・ド」とおりてくる練習です。

ドレミファソファミレド

これを1セットとして、1回歌うごとに、はじまりの音を半音ずつ上げたり、下げたりしていきます。

なぜ5つの音なの？

ドからソまでの5つの音は、はばがせまく、だれでも歌いやすい音のはんいです。いきなり広いはんいを歌うと、のどに力が入りやすくなりますが、5つの音なら、むりなく声を動かすことができます。

また、少しずつ高さをかえていくことで、低い声から高い声まで、声全体をまんべんなく動かすことができます。

5トーンスケールでできるようになること

5トーンスケールの練習を続けると、つぎのようなことを意識しやすくなります。

  • 声の高さが、なめらかにつながる
  • 音と音のあいだを、ていねいに移る
  • 高くなっても、声の色をかえずに歌う
  • 音の高さを、正しくとらえる

もちろん、練習の効果は人によってちがいます。ただ、毎日の発声練習の土台として、多くの教室でとり入れられている練習のひとつです。

5トーンスケールのやり方

準備するもの

  • ピアノやキーボード（なければ、スマホの鍵盤アプリでもよい）
  • 鏡（口の形や姿勢をたしかめるため）
  • 水

ネットには、5トーンスケールの伴奏音源もたくさんあります。音源に合わせて歌うのも、やりやすい方法です。

基本のやり方

  1. まっすぐ立ち、肩の力をぬく
  2. 鼻からゆっくり息をすう
  3. 出しやすい高さの「ド」から、「ドレミファソファミレド」と歌う
  4. 1回歌いおえたら、息をすって、半音上の音から同じように歌う
  5. 苦しくなる手前まで、少しずつ上げていく
  6. こんどは、半音ずつ下げながら、もとの高さまでもどってくる

はじまりの高さは、ふだん話すときの声に近い、らくに出せる高さがおすすめです。

どんな音で歌う？

5トーンスケールは、「ドレミ」と歌うだけでなく、いろいろな音で歌うことができます。

  • 「マ」「ナ」：口を大きく動かしやすく、ひびきを感じやすい
  • 「ウ」「ル」：口をすぼめるので、やわらかい声になりやすい
  • ハミング（んー）：のどにやさしく、練習のはじめにぴったり
  • くちびるブルブル：息の流れを感じやすい

はじめは、ハミングやくちびるブルブルからはじめて、なれてきたら「マ」や「ナ」にかえていく、という流れがおすすめです。

速さはゆっくりから

はじめは、1音ずつ、ていねいに歌いましょう。音と音のあいだを、なめらかにつなぐことを意識してください。なれてきたら、少し速くして、1息で軽く歌う練習もしてみましょう。

うまくできないときのコツ

高くなると、のどがしまる

高い音に近づくと、のどがきゅっとしまったり、あごが上がったりすることがあります。

  • あごを少しひいて、首のうしろを長くするイメージを持つ
  • 高い音ほど、「上にのばす」より「前に流す」イメージで歌う
  • 苦しいと感じたら、それ以上は上げない

高い音は、毎日少しずつ広がっていくものです。今日出なかった音を、むりに出そうとしなくても、だいじょうぶです。

声がひっくり返る

声が、とちゅうで急にうら声にかわってしまうことがあります。これは、多くの人がけいけんすることなので、心配しなくてだいじょうぶです。

  • ひっくり返るあたりの高さで、小さめの声で何回か歌ってみる
  • ハミングや「ウ」の音で歌ってみる
  • 声を大きくしすぎないようにする

音の高さがずれる

とくに「ファ」や、おりてくるときの「ミ」「レ」で、音の高さがずれやすくなります。ピアノの音をよく聞いてから歌う、1音ずつピアノといっしょに歌う、など、ゆっくりたしかめながら練習してみてください。

高くなると声の色がかわる

低いところではやわらかい声なのに、高くなると、きつい声になってしまうことがあります。高くなっても、低いところと同じ口の形、同じ声の色で歌うことを目指しましょう。録音して聞いてみると、声の色のちがいに気づきやすくなります。

5トーンスケールを、毎日の練習にとり入れる

5分でできる練習の例

  1. ハミングで5トーンスケール（低めから中くらいの高さまで）
  2. くちびるブルブルで5トーンスケール
  3. 「マ」で5トーンスケール（少し高めまで）
  4. 半音ずつ下げながら、もとの高さにもどる
  5. 練習している歌を1曲歌う

時間がない日は、1と3だけでもよいと思います。大切なのは、長い時間やることより、毎日少しずつ続けることです。

音のはんいを広げたいとき

5トーンスケールになれてきたら、「ドからドまで」の8つの音を歌う練習に進んでもよいと思います。音のはんいを広げる練習については、こちらの記事にまとめています。歌の音域を広げる方法。高い音・低い音を少しずつのばす練習

子どもと大人、それぞれのコツ

お子様の場合

お子様と練習するときは、「階段をのぼって、おりてこよう」と声をかけると、イメージしやすくなります。手で階段の形を作りながら歌うのも楽しいです。

お子様の声は、まだ育っているとちゅうです。高い声をむりに出させず、らくに出せるはんいで練習してください。お父様・お母様が先に歌って、まねをしてもらう形でもだいじょうぶです。

大人の場合

大人の方は、ひとりで練習すると、つい力が入ったり、高くまで上げすぎたりしがちです。鏡で姿勢をたしかめたり、録音して聞いたりしながら、自分の声のくせを知っていくのがおすすめです。

ひとりでの練習にまよったら、教室で先生に見てもらうのもよい方法です。5トーンスケールのような基本の練習も、先生に聞いてもらうと、自分では気づきにくいところを教えてもらえます。歌の教室さがし

5トーンスケールでよくある質問

何回くらい歌えばいいの？

決まった回数はありません。はじまりの音を半音ずつ上げていき、らくに出せる高さまでいったら、半音ずつ下げてもどってくる、という1往復だけでも、じゅうぶんな練習になります。時間があるときは、音の種類をかえて、2〜3往復してもよいと思います。

ピアノがなくてもできる？

できます。スマホの鍵盤アプリや、5トーンスケールの伴奏音源をつかう方法があります。また、音の高さを正しく合わせることにこだわりすぎず、「自分の声で、のぼっておりる」感じをつかむだけでも、声をならす練習になります。

歌う前と、歌ったあと、どちらにやるの？

5トーンスケールは、歌う前の発声練習としてつかわれることが多いです。歌ったあとに、低めの音でやさしくハミングの5トーンスケールをすると、声を落ちつかせる時間にもなります。

気をつけたいこと

  • 大きな声で歌いすぎない
  • 苦しくなる高さまで、むりに上げない
  • 練習のあいだに、水をのむ
  • のどに痛みやかすれを感じたら、その日はお休みする
  • 痛みやかすれが何日も続くときは、耳鼻科などのお医者さんに相談する

まとめ

  • 5トーンスケールとは、「ドレミファソファミレド」の5つの音をのぼっておりる発声練習
  • 1回ごとに、はじまりの音を半音ずつ上げ下げしていく
  • ハミングやくちびるブルブルからはじめ、「マ」や「ナ」にかえていくのがおすすめ
  • 高くなっても、あごを上げず、声の色をかえないように意識する
  • 苦しくなる手前で止めて、毎日少しずつ続ける
  • のどの痛みやかすれが続くときは、お医者さんに相談する

5トーンスケールは、シンプルだからこそ、毎日続けやすい発声練習です。練習で声がととのってきたら、その声で歌った歌を、だれかに聞いてもらうのもよい目標になります。
