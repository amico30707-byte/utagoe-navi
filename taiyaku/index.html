外国語の歌の対訳の作り方。ことばの意味を知って、歌を深めよう

更新日：2026年11月11日 ・ 書いた人：うみ

「イタリア語の歌を習いはじめたけれど、何を歌っているのか、よくわからない」 「先生に『対訳を作ってきてね』と言われたけれど、どうやって作ればいいの？」

声楽を習うと、イタリア語やドイツ語、フランス語など、外国語の歌に出会うことが多くなります。読み方はおぼえても、ことばの意味まではわからないまま歌っている、という方も少なくないと思います。

わたしは息子といっしょに、たくさんのコンクールに出てきました。

この記事では、外国語の歌の対訳の作り方にしぼってお話しします。歌詞を自分で訳すときに用意するもの、単語ごとに意味を調べる方法、楽譜への書きこみ方、そして訳を歌にいかすコツまでをまとめました。外国語が得意でなくても、だいじょうぶです。

対訳とは？なぜ自分で作るといいの？

対訳は、もとのことばと訳をならべたもの

対訳とは、もとの外国語の歌詞と、日本語の訳をならべて書いたものです。声楽では、歌の意味を知るために、対訳を作ったり、読んだりすることがよくあります。

楽譜集や本に、対訳がのっていることもあります。それを読むのも、もちろんよい方法です。

自分で作ると、ことばが体に入る

それでも、自分で対訳を作ってみるのには、よいところがあります。

  • ひとつひとつの単語の意味がわかる
  • どのことばが、どの音にのっているかがわかる
  • 大切なことばが、どこにあるかに気づける
  • 歌うときに、気持ちをこめる場所がはっきりする

本の訳は、日本語としてきれいにととのえてあることが多く、どの単語がどの意味なのか、わかりにくいこともあります。自分で単語ごとに調べると、ことばと音のつながりが見えてきます。

対訳づくりに用意するもの

楽譜と、歌詞をうつしたノート

まずは、歌う曲の楽譜を用意します。楽譜とは別に、歌詞だけをノートにうつしておくと、書きこみがしやすくなります。

ノートに歌詞をうつすときは、行と行のあいだを広くあけておきましょう。下に、単語の意味や訳を書きこむためです。

辞書や、調べる道具

単語の意味を調べるための道具を用意します。

  • 紙の辞書
  • 辞書のアプリや、インターネットの辞書
  • 声楽の歌詞の訳がのっている本

外国語の歌詞は、ふだんの会話では使わない、古いことばや詩のことばがつかわれていることもあります。辞書にのっていない形のときは、先生に聞いたり、声楽の本を見たりするとよいと思います。

本の訳は「答え合わせ」につかう

本やインターネットにのっている訳は、はじめから見るのではなく、自分で調べたあとの「答え合わせ」につかうのがおすすめです。先に答えを見てしまうと、単語を調べる楽しさがへってしまいます。

対訳の作り方、すすめる順番

はじめに　歌詞を、ことばのまとまりに分ける

まずは、歌詞をながめて、ことばのまとまりに分けてみましょう。点やピリオドなどの記号を目じるしにすると、分けやすくなります。

ひとつのまとまりが、日本語でいう「ひとつの文」にあたることが多いです。

つぎに　単語ごとに、意味を書く（逐語訳）

次に、ひとつひとつの単語の下に、日本語の意味を書いていきます。これを「逐語訳（ちくごやく）」といいます。むずかしいことばですが、「単語ごとの訳」という意味です。

たとえば、イタリア語なら、こんなふうに書きます。

  • amore　→　愛
  • cuore　→　心
  • caro　→　いとしい
  • mio　→　わたしの

このとき、日本語としてきれいにしようとしなくてだいじょうぶです。単語の意味を、そのまま書いていきましょう。

そのあと　ことばの形に気をつける

外国語では、同じ単語でも、形がかわることがあります。

  • だれが、のことか（わたし、あなた、など）
  • いつのことか（いま、むかし、これから）
  • ひとつか、たくさんか

辞書を引くときは、もとの形をさがす必要があることもあります。わからないときは、「ここがわからなかった」としるしをつけておき、レッスンで先生に聞いてみましょう。

さらに　文として、日本語にととのえる

単語の意味がそろったら、ことばのまとまりごとに、日本語の文にととのえていきます。外国語と日本語では、ことばのならび方がちがうことが多いので、意味が通るようにならびかえてみましょう。

この訳は、自分がわかればじゅうぶんです。かっこいい日本語にしなくてもかまいません。

ことばのならびをかえるときは、外国語の単語と、日本語の訳を線でむすんでおくのもおすすめです。どの単語が、日本語のどこに入ったのかが、あとで見てもすぐにわかります。歌うときに、その単語がどんな意味だったかを思い出しやすくなります。

さいごに　本の訳と、くらべてみる

自分の訳ができたら、本やインターネットの訳とくらべてみましょう。

  • 意味が大きくちがうところはないか
  • 自分の訳のほうが、わかりやすいところはないか
  • 本の訳で、はじめて気づいたことはないか

まちがえていたところは、なおしておきます。いくつかの訳をくらべると、同じ歌詞でも、訳す人によって、ことばのえらび方がちがうことにも気づけます。

楽譜への書きこみ方

歌詞の上や下に、単語の意味を書く

対訳ができたら、楽譜にも書きこんでおきましょう。楽譜の歌詞の近くに、えんぴつで、単語の意味を小さく書いておきます。

楽譜がごちゃごちゃして見にくくなるときは、大切な単語だけにしぼって書くのがおすすめです。

大切なことばに、しるしをつける

歌詞の中で、とくに大切なことばに、しるしをつけておきましょう。

  • 歌の気持ちの中心になることば
  • 何回もくりかえされることば
  • 長くのばす音や、高い音にのっていることば

大切なことばが、高い音や長い音にのっていることは、よくあります。作曲した人が、そのことばを大切にしていたのかもしれない、と考えてみるのも楽しいものです。

訳ノートは、ずっと取っておく

作った対訳のノートは、取っておきましょう。次に同じことばが別の曲で出てきたとき、見かえすことができます。続けていくうちに、知っている単語がふえていきます。

対訳を、歌にいかすコツ

意味を思いうかべながら歌う

対訳ができたら、ことばの意味を思いうかべながら歌ってみましょう。意味がわかると、同じ音でも、歌い方がかわってくることがあります。

  • やさしいことばは、やわらかく
  • よろこびのことばは、明るく
  • かなしいことばは、しずかに

意味を知ることで、強さや声の色を、自分でえらべるようになっていきます。

だれが、だれに歌っている歌かを考える

歌詞の意味がわかったら、「だれが、だれに向けて歌っているのか」を考えてみましょう。恋人に向けた歌なのか、自然をたたえる歌なのか、オペラの中で、ある人物が気持ちを話している歌なのか。

歌の場面を思いうかべられると、歌に気持ちがこもりやすくなります。曲の解釈については、こちらの記事でくわしく書いています。曲の解釈ってなに？作曲者や時代を知って、歌をもっと深めるための考え方

発音の練習とは、分けて考える

対訳は、ことばの意味を知るためのものです。読み方や発音の練習は、それとは別に、先生に教わりながらすすめましょう。イタリア語の発音のきほんは、こちらの記事でもまとめています。イタリア歌曲の発音のきほん。声楽をならう子ども・大人のために

対訳づくりで、気をつけたいこと

はじめから、完ぺきをめざさない

はじめての対訳づくりは、時間がかかることもあります。わからないところがあっても、気にしなくてだいじょうぶです。わかるところから少しずつ、で十分です。

先生のことばを、大切にする

先生によっては、その曲の意味や、場面について、くわしく話してくださることがあります。レッスンで聞いたことは、訳ノートに書きそえておきましょう。辞書だけではわからない、歌の気持ちのヒントがつまっています。

訳を人にくばるときは、気をつける

自分で作った訳を、発表会のプログラムなどにのせたいときは、先生に相談してからにしましょう。本の訳をそのままうつしてのせるのは、さけたほうが安心です。

まとめ

  • 対訳は、もとの外国語の歌詞と、日本語の訳をならべたもの
  • 自分で作ると、ことばと音のつながりがわかる
  • 歌詞をまとまりに分けて、単語ごとに意味を書くところからはじめる
  • 日本語の文にととのえたら、本の訳とくらべて答え合わせをする
  • 楽譜には、大切なことばの意味と、しるしを書きこむ
  • 意味と、歌の場面を思いうかべながら歌う
  • はじめから完ぺきをめざさず、わからないところは先生に聞く
