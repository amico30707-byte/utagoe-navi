ラテン語の合唱曲の発音のきほん。はじめての宗教曲を歌うときに

更新日：2026年11月7日 ・ 書いた人：うみ

「合唱団で、ラテン語の曲をやることになった。読み方がまったくわからない」 「ラテン語の歌の読み方は、英語とはちがうの？」

合唱をしていると、こんなふうにとまどうことがあると思います。合唱の曲には、ラテン語で書かれたものがたくさんあります。とくに、むかしから教会で歌われてきた宗教曲には、ラテン語の曲が多くあります。

わたしは息子といっしょに、たくさんのコンクールに出てきました。

この記事では、はじめてラテン語の合唱曲を歌う方のために、ラテン語の発音のきほんをまとめます。合唱でよく使われる読み方、母音と子音のポイント、まちがえやすいつづり、練習のすすめ方までを、単語の例を使ってお話しします。

ラテン語は、むずかしそうに見えますが、読み方のきまりはわりとシンプルです。いくつかのポイントをおさえれば、はじめての方でも、少しずつ読めるようになります。

ラテン語の合唱曲とは

むかしから歌われてきたことば

ラテン語は、むかしのヨーロッパで広く使われていたことばです。いまは日常の会話ではあまり使われていませんが、教会の祈りや音楽の中で、長く使われてきました。

そのため、合唱の世界では、ミサ曲やレクイエムなど、ラテン語で書かれた宗教曲がよく歌われます。合唱団の演奏会や、合唱のコンクールで出会うことも多いと思います。

宗教曲を歌うときの気持ち

宗教曲というと、「信仰がないと歌ってはいけないのかな」と心配になる方もいるかもしれません。合唱団では、いろいろな考え方の方が、音楽として宗教曲を歌っています。

大切なのは、そのことばや曲が、長い時間をかけて大事にされてきたものだと知って、ていねいに歌うことです。ことばの意味を知ると、曲の気持ちもつかみやすくなります。

合唱で使われることが多い読み方

教会ラテン語の読み方

ラテン語には、いくつかの読み方があります。合唱では、イタリア語に近い「教会ラテン語」の読み方が使われることが多いです。

ただし、曲の時代や国、指揮者の考え方によって、ちがう読み方をすることもあります。たとえば、ドイツ風の読み方や、むかしのラテン語に近い読み方を使う合唱団もあります。

まずは指揮者の方針に合わせる

合唱では、みんなが同じ読み方で歌うことが、とても大切です。ひとりだけちがう読み方をすると、ことばがそろわず、ひびきもまとまりにくくなります。

はじめに、指揮者や先生がどの読み方を使うのかを、たしかめておきましょう。この記事では、合唱でよく使われる教会ラテン語の読み方を中心に説明します。

母音のきほん

5つの母音は、ローマ字に近い

ラテン語の母音は、日本語の「あ・い・う・え・お」に近い音です。ローマ字の読み方に近いので、日本語を話す人にとっては、わりと読みやすいことばです。

  • a は「ア」
  • e は「エ」
  • i は「イ」
  • o は「オ」
  • u は「ウ」

たとえば、Gloria は「グローリア」、Dominus は「ドミヌス」と読みます。英語のように、つづりによって音がかわることは、あまりありません。

「ウ」は口をすぼめて

日本語の「う」は、口をあまり動かさずに言うことが多いです。ラテン語の u は、口びるを少し前にすぼめて、まるい「ウ」にすると、合唱らしいひびきになります。

「お」も同じように、口をたてにあけて、まるく歌うと、きれいにそろいやすくなります。

2つならんだ母音

ae と oe は、どちらも「エ」と読むことが多いです。たとえば、caeli は「チェーリ」のように読みます。

また、ei や eu などの母音がならぶときは、1つずつの音として歌うこともあれば、2つの音をなめらかにつなげることもあります。たとえば、Dei は「デーイ」のように、2つの音を分けて歌うことが多いです。どこで音をかえるかは、指揮者の指示を聞いてみてください。

まちがえやすい子音

c と g は、うしろの母音で音がかわる

ラテン語の読み方で、いちばんまちがえやすいのが c と g です。うしろにくる母音によって、音がかわります。

  • c のうしろが e・i・ae・oe のとき　「チ」の音（例：pacem は「パーチェム」）
  • c のうしろが a・o・u のとき　「カ・コ・ク」の音（例：cor は「コル」）
  • g のうしろが e・i のとき　「ジ」の音（例：genitum は「ジェニトゥム」）
  • g のうしろが a・o・u のとき　「ガ・ゴ・グ」の音（例：gloria は「グローリア」）

はじめは、楽譜を見ながら、c と g のうしろの母音に印をつけておくと、まちがいにくくなります。

組み合わせで音がかわるもの

ほかにも、文字の組み合わせで、読み方がかわるものがあります。

  • gn は「ニャ・ニュ」のような音（例：agnus は「アニュス」）
  • sc のうしろが e・i のとき　「シェ・シ」の音（例：descendit は「デシェンディト」）
  • ti のうしろに母音がくるとき　「ツィ」の音（例：gratias は「グラーツィアス」）
  • qu は「クゥ」のような音（例：qui は「クゥイ」）
  • xc のうしろが e・i のとき　「クシェ・クシ」の音（例：excelsis は「エクシェルシス」）

h と j の読み方

h は、ほとんど音を出さないことが多いです。たとえば、hosanna は「オザンナ」のように読みます。ただ、mihi のように、h を「キ」に近い音で読む読み方もあります。

j は「イ」の音になります。たとえば、Jesu は「イエズ」のように読みます。英語の「ジ」とはちがうので、気をつけましょう。

r は軽くはじく

r は、舌の先を上の歯のうらに軽くあてて、はじくように言います。日本語の「ら行」に近い音ですが、少しはっきりめに出すと、ことばが聞きとりやすくなります。ことばのとちゅうで2つならぶ rr は、少し長めに舌をふるわせることもあります。

ことばを読むときのコツ

アクセントのある場所を知る

ラテン語の単語には、強く読むところがあります。楽譜では、音の高さや長さで、自然にアクセントが表れていることが多いです。

たとえば、Dominus は「ド」、sanctus は「サン」に重みがあります。アクセントのない音まで強く歌うと、ことばがかたく聞こえるので、ことばの流れを大切にしましょう。

ことばの意味を調べる

ラテン語の曲を歌うときは、歌詞のおおまかな意味を知っておくと、歌い方がかわります。

  • Gloria は「栄光」
  • pacem は「平和」
  • Dominus は「主」
  • Amen は「そうでありますように」

楽譜に日本語の訳がついていることもあります。1つ1つの単語の意味を知ると、どこを大切に歌えばいいのかが、わかりやすくなります。

子音は、母音の前に早めに

合唱では、子音を出すタイミングが大切です。子音を、音の前に少し早めに出して、母音を拍の頭にあわせると、ことばと音がそろいやすくなります。

また、ことばの終わりの s や t は、みんなでそろえて出すことが多いです。おわりの子音をどこで出すかは、指揮者の指示をよく見ましょう。

楽譜への書きこみ方

カタカナは、あくまで助け

はじめは、楽譜にカタカナで読み方を書きこむと、安心して歌えます。ただ、カタカナだけにたよると、日本語の発音に引っぱられやすくなります。

  • c や g の音がかわるところに、小さく印をつける
  • 母音がならぶところに、区切りの線を入れる
  • 読みにくい単語だけ、カタカナを書く

全部の単語にカタカナを書くより、まちがえやすいところだけに書いておくと、楽譜も見やすくなります。

えんぴつで、うすく書く

書きこみは、あとで消せるように、えんぴつでうすく書いておきましょう。指揮者の指示で読み方がかわることもあるので、すぐに直せるようにしておくと安心です。

はじめてのラテン語の曲の練習のしかた

ステップ1　ことばだけを読む

いきなり歌うのではなく、まずはことばだけを、ゆっくり声に出して読んでみましょう。音の高さは気にせず、1つずつの音をはっきり読みます。

ステップ2　リズムにのせて読む

読みなれてきたら、曲のリズムにあわせて、ことばを読んでみます。手をたたきながら読むと、ことばと拍の関係がつかみやすくなります。

ステップ3　母音だけで歌う

子音をぬいて、母音だけでメロディを歌ってみる練習もあります。たとえば、Gloria なら「オ・イ・ア」のように歌います。母音の形がそろうと、合唱のひびきがきれいになります。

ステップ4　ことばをつけて歌う

さいごに、ことばをつけて、ゆっくり歌ってみましょう。はじめはテンポをおとして、ことばがはっきり言えるようになってから、もとの速さにもどします。

自分の歌を録音して聞いてみると、読み方のまちがいや、母音の形のちがいに気づきやすくなります。

イタリア語の発音もヒントになる

教会ラテン語の読み方は、イタリア語の読み方に近いところがあります。イタリア語の歌を習ったことがある方は、その知識が役に立つと思います。くわしくは、こちらの記事も読んでみてください。イタリア歌曲の発音のきほん。声楽をならう子ども・大人のために

教会の合唱にも興味がある方へ

ラテン語の宗教曲を歌って、教会の合唱にも興味をもった方は、こちらの記事も参考にしてみてください。聖歌隊に入りたい方へ。教会の合唱に初心者が参加するときに知っておきたいこと

わからないところは、そのままにしない

読み方に自信がない単語は、練習のときに指揮者やパートリーダーに聞いてみましょう。ほかの人も、同じところで迷っていることがよくあります。みんなでたしかめることで、合唱全体のことばがそろっていきます。

まとめ

  • 合唱では、教会ラテン語の読み方が使われることが多い。まずは指揮者の方針に合わせる
  • 母音は「ア・エ・イ・オ・ウ」でローマ字に近い。ae と oe は「エ」
  • c と g は、うしろの母音で音がかわる。印をつけておくとまちがえにくい
  • gn、sc、ti、qu、h、j など、まちがえやすい読み方をおぼえておく
  • ことばの意味を知ると、歌い方がかわる
  • 練習は「読む」「リズムで読む」「母音で歌う」「ことばで歌う」の順で

ラテン語の曲は、はじめはむずかしく感じても、読み方のきまりがわかってくると、ことばのひびきの美しさを楽しめるようになります。
