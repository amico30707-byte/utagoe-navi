リモート合唱のやり方。はじめてでもできる、歌の重ね録りの手順

更新日：2026年11月11日 ・ 書いた人：うみ

「合唱団の練習があつまれないとき、オンラインでいっしょに歌えないかな」 「遠くに住む家族や友だちと、1曲歌ってみたい」

はなれた場所にいる人どうしでも、それぞれが自分の歌を録って、あとでひとつに重ねれば、合唱のように聞こえる作品を作ることができます。これが、リモート合唱です。歌の重ね録りとも言われます。

わたしは、息子といっしょに、たくさんの歌のコンクールに出てきました。家で歌を録ることのむずかしさと楽しさは、少しわかるつもりです。

この記事では、リモート合唱のやり方を、はじめての方でも動けるように、手順ごとにお話しします。まとめ役の方がすること、歌う人がすること、そして、ひとりで何パートも重ねるときのコツも書きました。

リモート合唱とは？

リモート合唱は、ひとりひとりが別の場所で歌を録り、それをまとめ役の人がひとつに重ねて仕上げる合唱です。

  • みんなが同じ時間にあつまらなくてよい
  • 遠くに住む人とも、いっしょに歌える
  • 自分のペースで、何度でも録りなおせる

一方で、オンラインの通話でいっしょに歌おうとすると、音がおくれて届くため、声をそろえるのはとてもむずかしいです。そのため、リモート合唱では「同じ見本を聞きながら、それぞれが録る」という形がよく使われます。

はじめに決めておくこと

曲と、パートの分け方

まず、歌う曲を決めます。はじめてなら、テンポがあまり変わらず、長すぎない曲がおすすめです。

  • 2部か3部くらいの、パートが少ない曲
  • 3分から4分くらいの曲
  • とちゅうで速さが大きく変わらない曲

だれがどのパートを歌うかも、先に決めておきましょう。合唱のパートについては、こちらの記事でくわしく書いています。合唱のパートのちがい。ソプラノ・アルト・テノール・バスと、自分に合うパートの見つけ方

まとめ役の人

リモート合唱では、みんなの音を集めて重ねる「まとめ役」が必要です。音や映像の編集にくわしい人がいれば、その人にお願いするとスムーズです。

しめきりと、送り方

  • いつまでに録って送るか
  • どうやって送るか（ファイルを送れるサービスなど）
  • ファイルの名前のつけ方（たとえば「ソプラノ・山田」のように）

ファイルの名前を決めておくだけで、まとめ役の人の手間がぐっとへります。

動画にするか、音だけにするか

顔をうつした動画にするか、音だけにするかも決めておきます。動画にするなら、スマホをたてにするか、よこにするかを、みんなでそろえておきましょう。そろっていないと、ならべたときに見た目がばらばらになります。

ガイド音源を作る

ガイド音源とは

ガイド音源は、みんなが録るときに、イヤホンで聞く見本の音です。全員がこれに合わせて歌うことで、あとで重ねたときに、タイミングがそろいやすくなります。

ガイド音源には、こんな音を入れることが多いです。

  • 伴奏（ピアノなど）
  • テンポを知らせる「カッ、カッ」という音
  • 各パートのメロディー（あると歌いやすい）

歌いだしの前に合図を入れる

曲がはじまる前に、テンポに合わせた合図の音を何回か入れておくと、歌いだしがそろいやすくなります。テンポを一定にたもつ練習については、こちらの記事も参考になると思います。メトロノームを使った歌の練習。リズムが安定するコツと、速さの決め方

パートごとのガイドを用意する

自分のパートの音がわかりにくい人のために、そのパートのメロディーを少し大きめにしたガイドを、パートごとに作っておくと親切です。

歌う人がすること

1. ガイド音源で、しっかり練習する

録る前に、ガイド音源に合わせて何度か歌ってみましょう。歌いだし、息つぎの場所、曲のおわり方を、からだにしみこませておくと、録るときにあわてません。

2. 録る場所をととのえる

  • まわりの音（テレビ、エアコン、車の音など）が少ない部屋
  • かべに近すぎない場所
  • 動画なら、顔が明るくうつる場所

カーテンをしめたり、ふとんやクッションがある部屋で録ったりすると、音のひびきが落ちついて、重ねたときに聞きやすくなります。

3. イヤホンでガイドを聞きながら録る

ガイド音源は、かならずイヤホンで聞きながら歌います。スピーカーから流すと、ガイドの音まで録音に入ってしまい、重ねたときに音がにごってしまいます。

片方の耳だけイヤホンをすると、自分の声も聞きやすくなります。イヤホンをつけて歌うときのコツは、こちらの記事でくわしく書いています。歌の練習でイヤホン・ヘッドホンを使うコツ。音量・片耳・録音との組み合わせ方

4. 録りはじめに「手拍子」を入れる

録画や録音をはじめたら、歌う前に、ガイドの合図に合わせて1回手をたたいておきましょう。まとめ役の人が、この手拍子の音を目じるしにして、みんなのタイミングを合わせやすくなります。

5. 何回か録って、いちばんよいものを送る

1回で完ぺきに歌えなくても、だいじょうぶです。何回か録って、聞きなおして、いちばん気持ちよく歌えたものを送りましょう。

録ったあとに聞くときは、「声がしっかり入っているか」「雑音が大きすぎないか」「歌いだしがガイドとずれていないか」を見ておくと安心です。

まとめ役の人がすること

1. 音のタイミングをそろえる

集まったファイルを、音を重ねられる編集のソフトやアプリに入れます。録りはじめの手拍子の位置を目じるしにして、全員のタイミングをそろえます。

2. 音量をととのえる

人によって、録音の音量はばらばらです。ひとりの声だけが大きすぎたり、小さすぎたりしないように、パートごとのバランスを見ながら、音量をととのえます。

3. ひびきを少しだけ足す

家で録った声は、ひびきが少なく、かたく聞こえることがあります。編集のソフトやアプリでひびきを少し足すと、みんなの声がなじみやすくなります。足しすぎると、ことばが聞きとりにくくなるので、ほんの少しにしておきましょう。

4. 映像をならべる

動画にする場合は、みんなの映像をならべます。人数が多いときは、パートごとにまとめたり、曲のとちゅうで見せる人をかえたりすると、見ていて楽しい作品になります。

ひとりで重ね録りをするときのコツ

リモート合唱は、ひとりでもできます。自分で何パートも歌って重ねる「ひとり合唱」です。

いちばん下のパートか、メロディーから録る

はじめに、曲の土台になるパートを録ると、そのあとのパートが歌いやすくなります。

  • メロディーから録って、ほかのパートを足していく
  • いちばん低いパートから録って、上に重ねていく

どちらがやりやすいかは、曲や自分の声によってちがいます。

前に録った声を聞きながら、次のパートを録る

2つめのパートからは、ガイド音源と、前に録った自分の声を聞きながら歌います。音がとりにくいときは、自分の声を小さめにして、伴奏を大きめにすると歌いやすくなることがあります。

声の高さに、むりをしない

ひとりで何パートも歌うと、自分の声に合わない高さを歌うことになりがちです。むりに高い声や低い声を出しつづけると、のどがつかれてしまいます。高さをかえられるなら、自分の声に合わせて調整しましょう。

のどに痛みやかすれを感じたら、その日はやめて声を休めてください。何日も続くときは、耳鼻科などのお医者さんに相談してください。

はじめてのリモート合唱で、よくあるつまずき

歌いだしが、人によってずれる

ガイド音源の合図を聞きのがすと、歌いだしがずれやすくなります。合図の回数を少し多めにしたり、歌いだしの前に「さん、はい」の声を入れたりすると、そろいやすくなります。

声の大きさが、ばらばら

スマホとの距離が人によってちがうと、声の大きさもかわります。「スマホから口まで、手のひら2つ分くらい」など、めやすをみんなで決めておくと安心です。

しめきりに、まにあわない人がいる

しめきりの少し前に、「録れましたか」と声をかけるだけでも、まにあう人がふえます。まとめ役の方の負担を考えて、しめきりにはよゆうをもたせておきましょう。

作品を公開するときに気をつけたいこと

曲の権利のきまりをたしかめる

できあがった作品をネットで公開するときは、使った曲や伴奏について、公開してよいかどうかのきまりをたしかめておきましょう。きまりは、曲や公開する場所によってちがいます。

顔や名前の出し方を、みんなで決める

参加した人の中には、顔や名前を出したくない人もいます。とくにお子様が参加するときは、お父様・お母様とよく相談して決めましょう。

まとめ

  • リモート合唱は、ひとりひとりが録った歌を、あとで重ねて作る合唱
  • 曲、パート、まとめ役、しめきり、ファイルの名前を先に決める
  • 合図の音を入れたガイド音源を作り、全員がイヤホンで聞きながら録る
  • 録りはじめに手拍子を入れると、タイミングを合わせやすい
  • まとめ役は、タイミング、音量、ひびき、映像の順にととのえる
  • ひとりで重ね録りするときは、土台のパートから録り、むりな高さはさける
  • 公開するときは、曲の権利と、顔や名前の出し方をたしかめる
