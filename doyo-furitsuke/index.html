童謡にふりつけをつけて歌おう。小さなお子様と楽しむ、歌の振り付けの作り方

更新日：2026年11月11日 ・ 書いた人：うみ

「童謡に、かんたんな振り付けをつけてあげたい」 「歌に合わせて体を動かすのが好きな子。でも、どんな動きにしたらいいのかわからない」

小さなお子様と歌っていると、こんなふうに思うお父様・お母様も多いと思います。テレビや動画で、歌に合わせて手を動かしている子を見て、「うちでもやってみたい」と感じることもありますよね。

わたしは息子といっしょに、たくさんのコンクールに出てきました。歌は、声だけでなく、体ぜんたいで楽しむものだと感じています。

この記事では、童謡に振り付けをつけて歌うときの、動きの作り方にしぼってお話しします。歌詞から動きを思いつくコツ、むずかしくしない手順、年れいごとのめやす、おうちで楽しむときに気をつけたいことをまとめました。ダンスが苦手なお父様・お母様でも、だいじょうぶです。

手あそびや、歌いながらのあそびそのものについては、こちらの記事にまとめています。幼児とおうちの歌あそび。0〜5歳の歌の時間のつくり方

童謡に振り付けをつけると、どんなよさがある？

歌詞の意味が、体でわかる

小さなお子様にとって、童謡の歌詞には、知らないことばや、昔のことばがたくさん出てきます。そこに動きがつくと、「ここは、かたつむりのことを歌っているんだな」と、目と体でわかりやすくなります。

ことばの意味がわかると、歌い方にも気持ちがこもりやすくなります。

歌詞をおぼえやすくなる

動きとことばをセットにすると、歌詞を思い出しやすくなる子も多いです。「手をぐるぐるしたら、つぎはこのことば」というように、動きが歌詞の目じるしになってくれます。

歌うのが、もっと楽しくなる

じっと立って歌うのは、小さなお子様には少しむずかしいこともあります。体を動かしながらだと、自然に笑顔になって、声も明るくなりやすいです。

ただし、振り付けはあくまで「歌を楽しむためのもの」です。上手に動けるかどうかより、親子でいっしょに楽しめるかどうかを大切にしてください。

振り付けをつけやすい童謡のえらび方

ことばに「もの」や「動き」が出てくる歌

振り付けをつけやすいのは、歌詞の中に、目に見えるものや、動きを思いうかべやすいことばが出てくる歌です。

  • 生きもの（かたつむり、うさぎ、かめなど）
  • 自然（花、雨、山、お日さまなど）
  • 動き（歩く、ころがる、とぶなど）

たとえば、「かたつむり」「うさぎとかめ」「どんぐりころころ」「春が来た」などは、昔から歌われてきた童謡で、歌詞からいろいろな動きを思いつきやすい歌です。

短くて、くりかえしのある歌

はじめての振り付け作りには、1番が短く、同じメロディーがくりかえされる歌がおすすめです。くりかえしの部分は同じ動きにできるので、お子様もおぼえやすくなります。

お子様が好きな歌

いちばん大切なのは、お子様がその歌を好きかどうかです。好きな歌なら、動きを考えるところから楽しんでくれます。どの歌にするか、お子様に聞いてみるのもいいですね。

振り付けの作り方　4つの手順

手順1　歌詞を声に出して読んでみる

まずは、メロディーをつけずに、歌詞をゆっくり読んでみましょう。読みながら、「目に見えるもの」「動きのことば」に、えんぴつでしるしをつけていきます。

たとえば「かたつむり」なら、かたつむりそのもの、つの、頭などのことばに、しるしがつくと思います。

手順2　しるしをつけたことばに、動きを1つずつつける

しるしをつけたことばに、かんたんな動きをつけていきます。このとき、あまりたくさんの動きを入れないのがコツです。

  • かたつむり　→　手をグーにして、ゆっくり前に出す
  • つの　→　人さし指を2本立てて、頭の上にのせる
  • うさぎ　→　手を頭の上にのせて、耳のようにする
  • かめ　→　背中をまるくして、ゆっくり歩くまね
  • どんぐり　→　両手で小さなまるを作る
  • ころころ　→　両手をぐるぐる回す
  • 花　→　両手を顔の横で、ぱっとひらく

動きは、ことばの「形」をまねるか、ことばの「動き」をまねるか、どちらかで考えるとうかびやすくなります。

手順3　つなぎの動きを決める

しるしのないところは、むりに動きをつけなくてだいじょうぶです。体をやさしく左右にゆらす、手びょうしをする、など、だれでもできる「つなぎの動き」を1つ決めておくと、ぜんたいがまとまります。

つなぎの動きを決めておくと、お子様が動きをわすれたときにも、すぐにもどってこられます。

手順4　歌いながら、ゆっくり合わせる

動きが決まったら、歌いながら合わせてみましょう。はじめは、いつもよりゆっくりのテンポで歌うのがおすすめです。

できるようになったら、少しずつふだんの速さにしていきます。うまくいかないところは、動きをへらしたり、かんたんにしたりしてかまいません。

年れい別　振り付けのめやす

お子様の育ち方には、一人ひとりちがいがあります。ここに書くのは、あくまでめやすです。

2〜3歳ごろ

この年ごろは、大人のまねをすることが楽しい時期です。手をたたく、手をひらく、体をゆらすなど、1つか2つのかんたんな動きで十分です。

歌は大人が歌って、お子様は動きだけ、という楽しみ方でもだいじょうぶです。

4〜5歳ごろ

少しずつ、ことばと動きを合わせられるようになってくる子が多いです。歌詞に合わせて、3つから5つくらいの動きを入れてみましょう。

「つぎは、どんな動きにする？」と、お子様に考えてもらうのもおすすめです。自分で考えた動きは、とてもよくおぼえてくれます。

6歳ごろから

手と足をいっしょに動かしたり、まわったりする動きも、楽しめるようになってくる子が多いです。きょうだいやお友だちと、向かい合って動きを合わせるのも楽しいですね。

ただ、動きが多くなると、歌がおろそかになりやすくなります。「歌がいちばん、動きは二番」という気持ちを、わすれないようにしましょう。

振り付けをつけて歌うときのコツ

動きが大きくなりすぎないようにする

動きに夢中になると、息がはずんで、歌の声が小さくなったり、とぎれたりすることがあります。手の動きを中心にして、足の動きはひかえめにすると、歌いやすくなります。

顔は前を向いて歌う

下を向いたり、横を向いたりしながら歌うと、声がこもりやすくなります。動きをつけても、顔はなるべく前を向くように声をかけてあげてください。

大人がまず楽しそうにやってみせる

小さなお子様は、お父様・お母様の様子をよく見ています。大人が少しおおげさなくらい、楽しそうに動いてみせると、お子様も安心してまねしてくれます。

上手でなくても、まったく問題ありません。はずかしがらずにやってみることが、いちばんのお手本になります。

できたところをほめる

「うさぎの耳、かわいかったね」「ころころが、とってもじょうずだったよ」など、できたところを具体的にほめてあげましょう。まちがえたところを直すより、楽しかった気持ちをのこしてあげることが大切です。

おうちで楽しむときに気をつけたいこと

まわりの安全をたしかめる

体を動かすときは、まわりに角のある家具や、こわれやすいものがないか、先にたしかめておきましょう。すべりやすいくつ下や、床においたおもちゃにも気をつけてください。

つかれたら、すぐに休む

歌いながら体を動かすのは、思ったよりつかれるものです。お子様が「もうやめたい」と言ったら、むりに続けず、休けいしましょう。お水をのんで、のどもやすめてあげてください。

本番やコンクールのルールは、先にたしかめる

発表会やコンクールで歌うときは、振り付けをつけてよいかどうか、会によって考え方がちがいます。歌そのものを聞いてもらう会では、大きな動きはひかえたほうがよいこともあります。出る前に、要項などでたしかめておくと安心です。

お遊戯会で歌うときの、おうちでの練習については、こちらの記事も読んでみてください。幼稚園・保育園のお遊戯会の歌の練習。おうちでできるサポートと、当日までのすごし方

振り付け作りでよくあるなやみ

お子様が動きをおぼえられない

動きが多すぎるのかもしれません。動きを半分にへらしてみたり、いちばん好きな部分だけに動きをつけたりしてみましょう。全部をおぼえなくても、楽しく歌えていればそれでじゅうぶんです。

歌わずに、動きだけになってしまう

動きが楽しくて、歌うのをわすれてしまう子もいます。そんなときは、まず動きなしで1回歌い、そのあと動きをつけて歌う、という順番にしてみましょう。

大人がアイデアを思いつかない

むずかしく考えなくてだいじょうぶです。「このことば、どんなふうに見える？」とお子様に聞いてみると、大人が思いつかないような、おもしろい動きを考えてくれることがよくあります。

まとめ

  • 童謡に振り付けをつけると、歌詞の意味がわかりやすく、おぼえやすくなる
  • 生きものや自然、動きのことばが出てくる、短い歌がつけやすい
  • 作り方は「歌詞を読む」「ことばに動きをつける」「つなぎの動きを決める」「ゆっくり合わせる」の4つ
  • 年れいに合わせて、動きの数をかえる
  • 動きは大きくしすぎず、顔は前を向いて歌う
  • まわりの安全をたしかめ、つかれたらすぐに休む

振り付けをつけて楽しく歌えるようになったら、その歌をだれかに聞いてもらうのも、すてきな目標になります。
